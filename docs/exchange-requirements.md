# セル間白点交換（タルモン方式）要件

2×2 セルの白点「配置」だけでなく、隣接セル間の白点「個数」も知覚誤差で
見直す後段（セル間白点交換）と、それを束ねた変換モードの要件。
設計は `docs/exchange-design.md`、画面側は `docs/web-requirements.md` §10。

## 1. 具体的な表面（先に結論）

### コア（ライブラリ）

- `ConversionOptions` に `exchange: usize` を追加する。交換ラウンド数。
  省略時（`Default`）は **0**＝交換なし。
- `ConversionResult` に `exchange: usize`（実際に適用したラウンド数）を返す。
- モード解決をコアが持つ：`mode_preset(name) -> Option<ModePreset>`。
  `ModePreset { diffusion: bool, exchange: usize }`。

| モード名 | diffusion | exchange | 向いている入力 |
|---|---|---|---|
| `photo` | オン | 3 | 写真。階調の滑らかさが勝つ |
| `illustration` | オフ | 3 | アニメ・イラスト。平坦部の清潔さが勝つ |

- 交換ラウンド数の既定（モード共通）は `MODE_EXCHANGE_ROUNDS = 3`。
  実測根拠は設計 §4。

### CLI

- `--exchange N`（0〜10、既定 0）：交換ラウンド数を直接指定する。
- `--mode photo|illustration`：モードの束ね（拡散＋交換）を一括指定する。
  後に書いた `--no-diffusion` / `--exchange` が個別に上書きする。
- 標準出力の適用値表示に `exchange=N` を追加する（従来の
  `cell diffusion=on|off` は維持）。

使用例：

```
# 写真向け（拡散あり＋交換3）
pic2gray4px photo.jpg --width 384 --mode photo

# イラスト向け（拡散なし＋交換3）
pic2gray4px art.png --width 384 --mode illustration

# 実験用に交換だけを直接指定
pic2gray4px photo.jpg --width 384 --exchange 3
```

### WASM

- `convert_rgba_adjusted` に末尾引数を追加する：
  `mode_name: Option<String>`、`exchange_rounds: Option<u32>`。
  - `mode_name` がある場合、拡散と交換はモードの束ねで決まり、
    `diffusion` 引数は無視される。
  - `mode_name` と `exchange_rounds` の同時指定はエラー。
  - 未知のモード名はエラー。
  - どちらも無い場合は従来通り（拡散＝引数、交換＝0）。
- `ConvertResult` に `diffusion_used` / `exchange_used` ゲッタを追加する。
- 旧 `convert_rgba` は無変更（交換なしのまま）。

## 2. アルゴリズムの要件

- 交換は配置最適化の後段として動く。各ラウンドで、直交隣接セルペアに
  ついて白点1個の移動（両方向）を、ペア合同の全パターン組み合わせで
  評価し、配置最適化と同じ知覚コスト（9×9 カーネル）が下がる場合だけ
  確定する。各ラウンドの後に配置のみの磨き直し（ポリッシュ）を回す。
- **ペアの白点合計は保存される**。したがって画像全体の白点総数も
  変換前（個数決定段の結果）と完全一致する。階調の帳尻は個数決定段
  （拡散）が持ち、交換は配置の自由だけを増やす。
- セル個数はパディング必須白の下限（min_count）以上 4 以下に収まる
  場合だけ移動できる。
- 交換 0 のとき、出力は従来と**バイト一致**する（ゴールデンテストと
  従来バイナリとの実比較で担保）。

## 3. 自動探索との関係

- contrast / unsharp の候補探索は**交換なし**で回す（スコアの比較可能性と
  速度のため）。交換は勝った候補にだけ、最後に1回適用する。
  交換は全候補を同方向に改善するため、勝者選びが歪む心配は小さい、
  というのが実験で得た前提である。

## 4. 検証済みの効果（比較実験、幅384・warm×contrast 固定）

目的関数 E（誤差とそのぼかしの内積。配置コストが厳密に最小化する量）
での改善：拡散＋交換は従来比 −1.5%〜−4.9%（写真系7画像すべてで改善）。
目視判定（作者とレビュアーで一致）：

- 写真系は「拡散＋交換」が最も綺麗。
- アニメ・イラスト系は「交換のみ（拡散なし）」が最も綺麗
  （平坦部に拡散由来の斑点が出ない）。
- 拡散なし単独はグラデーションに縞（段差）が出る。拡散は残す価値がある。

→ この2系統の勝ち筋を、そのまま2モードとして提供する。

## 5. コスト

- 幅384で変換時間は従来の約2〜3倍（交換3ラウンド時）。
  Web では 400万画素キャップの内側で効くため、実用範囲。
