# 要件定義書

## 目的

2×2 画素の白点数で 5 段階の階調を作り、周囲に合う点の配置を選ぶことで、写真を 1-bit の白黒画像でも判別しやすくする。Raspberry Pi と小型モノクロプリンターで使える CLI とする。

## 機能要件

1. 実行ファイル名は `pic2gray4px`。PNG、JPEG、WebP、BMP、TIFF、PNM を読み、PNG 色種 0・ビット深度 1 で保存する。
2. 2×2 セルの白点数は 0〜4。標準ではセル単位の蛇行 Floyd–Steinberg 残差拡散で丸め誤差を隣へ渡す。`--no-diffusion` は元実験と同じ独立丸めに戻す。
3. 白点数を固定してから候補配置を全列挙し、元実験の二次形式の目的関数で最大 10 回最適化する。前後の走査方向を交互にし、変更がなくなれば停止する。
4. コントラスト・アンシャープは標準で画像ごとに保守的に自動選択する。`--contrast auto|off|C`（C は 0〜3）、`--unsharp auto|off|A`（A は 0〜2）で変更できる。実際の値を標準出力に表示する。
5. `--width PIXELS` は縦横比を保ってリサイズする。`--passes N` は 0〜10。出力パス省略時は入力と同じ場所の `<stem>-4px.png`。既存出力は拒否し、`--force` の場合だけ上書きする。入力そのものは `--force` でも上書きしない。
6. 透過は白地へ合成し、EXIF 向きが読めれば反映する。奇数寸法は右・下へ白画素を補う。失敗時は標準エラー出力に理由を表示して非 0 で終了する。

## 品質と制約

- PNG は可逆圧縮。圧縮率と最小ファイルサイズは画像によって異なる。
- 元実験の RAW 入力から独立丸めモードで画素単位の再現を検証する。新しい残差拡散モードは提供された比較画像と照合する。
- 自動前処理は飽和増加と RMS 変化量を制限する推定であり、知覚品質の最適化ではない。平坦画像や細線主体の画像は補正を控える。
- 白点数の残差拡散を有効にすると、元実験の「各セルの平均を個別に丸める」性質は変わる。配置最適化中の白点数は維持する。
