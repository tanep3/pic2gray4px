# アルゴリズム解説書

## 元の VM 実験を再現する部分

入力を 8-bit グレースケールにし、各画素を `u8/255` の `f64` にする。2×2 セルの白点数は `floor(4画素の和 + 0.5)`。初期配置は左上、右下、右上、左下の順で白を置く。候補は `[左上,右上,左下,右下]` の 0/1 を辞書順に全列挙し、白点数が同じものだけ使う。白 2 個なら斜めも含めた 6 通り。

目的カーネル `K` は、標準偏差 0.65 と 1.25 の 9×9 ガウスをそれぞれ正規化し、各々を自己畳み込みして中心 9×9 を**再正規化せず**切り出し、重み 0.55 と 0.30 で足す。中心へ 0.15 を加える。残差 `r = K * (出力 - 元画像)` の画像外はゼロとする。4 画素の変更量を `δ`、`Q[i,j] = K[画素i−画素j]` とすると、候補の目的値差は `2δ·r + δᵀQδ`。最小候補が `-1e-10` より小さいときだけ変更し、残差をすぐ更新する。行と列の順をともに順方向・逆方向と交互にし、変更ゼロか最大 10 走査で止める。

`--no-diffusion --contrast off --unsharp off` では、提供された 250×122 グレー RAW 2枚に対して、Python 試作の出力 RAW と **画素差 0**、走査別変更数も一致した。これはリサイズや前処理を除いた最適化本体の照合である。

## 新しい白点数の残差拡散

標準では、セルの 4 画素の和に前セルからの残差を足して `floor(和 + 0.5)` で白点数を決める。量子化残差を、セル行を蛇行走査しながら、進行方向へ 7/16、次行の逆方向へ 3/16、真下へ 5/16、次行の進行方向へ 1/16 渡す。画面外への残差は捨てる。配置最適化は上記の元実験と同じ。提供されたセル残差拡散の完成画像 3 枚と **画素差 0** を確認した。白パディング部分は白を必須とするため、奇数寸法の端では元実験にない制約が加わる。

## 前処理と自動選択

透過を白へ合成した後、コントラスト `clip((Y−0.5)×C+0.5,0,1)`、続いてアンシャープ `clip(Y+A×(Y−blur3(Y)),0,1)` を適用する。`blur3` は `[[1,2,1],[2,4,2],[1,2,1]]` で、画像端は存在画素だけで正規化する。この前処理は提供された Python 比較実験の Pillow フィルターと同一ではない。

自動値の候補は C が 1.02〜1.12（0.02刻み）、A が 0.15、0.25、0.35、0.5。透過度 50% 以上の画素で測り、コントラストの追加飽和画素を 1 ポイント以内、元画像との差 RMS を 6/255 以内、アンシャープの追加飽和を 0.5 ポイント以内、直前画像との差 RMS を 3/255 以内に制限する。実質的な変化が 0.25/255 未満なら採用しない。10〜90 パーセンタイルの明度差が 0.1 未満、または対象画素が 16 未満なら C=1、A=0。飽和判定は明度 1/255 以下または 254/255 以上。これらは安全側の経験則であり、完成画像の見た目を評価していない。最良の画質を保証しない。
